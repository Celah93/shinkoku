# 2027年分の所得税計算

`tax calc-income`・`tax calc-deductions`・`tax sanity-check` は2027年分を受け付ける。対応する所得区分の範囲で年間の控除・税額・源泉徴収・予定納税の精算まで計算する。個別の税額計算への対応と、国税庁の画面・申告書様式への転記確認は分ける。

## 年分で切り替わる計算

| 項目 | 2025年 | 2026年 | 2027年 |
|---|---|---|---|
| 復興特別所得税 | 2.1% | 2.1% | 1.1% |
| 防衛特別所得税 | なし | なし | 1% |
| ひとり親控除 | 35万円 | 35万円 | 38万円 |
| 青色申告特別控除の最高額 | 65万円 | 65万円 | 75万円（要件あり） |
| 給与所得控除と公的年金等控除の合計上限 | なし | なし | 280万円 |

2027年の基礎控除・給与所得控除・配偶者関連控除・扶養の所得要件・23歳未満扶養親族の生命保険料控除特例は、確認済みの2026年の表を引き継ぐ。2027年入居の住宅ローン控除も、住宅区分別の上限・期間を確認して追加した。2028年以後の年間申告計算には拡張しない。[住宅ローンの単体計算](housing-loan-standalone.md)では2030年入居まで扱い、面積・所得・借入期間を追加で検証する。年間計算の既存経路の適格性をすべて自動判定するものではない。

青色控除は金額を指定するだけでは適格にならない。75万円には期限内の電子申告と、優良帳簿又はデジタルシームレス保存・届出等を確認する。[適用判定](tax-eligibility.md)を参照する。

## 特別所得税の端数と結果

基準所得税額は、対応する国内の税額控除を引いた所得税に高所得特例の加算額を足した `income_tax_after_minimum_tax`。加算がなければ `income_tax_after_credits` と同額。2027年はこの値をそれぞれ11倍・10倍した整数の分子と、分母1000を保持する。分子を合算した後に円未満を切り捨て、所得税に加える。源泉徴収・予定納税の控除後、納付額だけを100円単位に切り捨てる。還付は円単位で精算する。

`reconstruction_tax` と `defense_tax` は円単位の参考内訳。個別に丸めてから足したときの差額を `special_tax_rounding_adjustment` に返す。例えば基準所得税額999円では、参考内訳10円・9円に丸め差1円を加え、特別所得税の合計20円となる。`income_special_tax_detail` に分子・分母・合計も残す。新様式の個別欄への転記方法は、様式公開後に確認する。

給与収入500万円、他の所得・控除なしの場合、2027年は所得税154,500円、復興税の参考内訳1,699円、防衛税1,545円、合計157,744円。前払いがなければ納付額157,700円、源泉徴収20万円なら還付42,256円となる。

## 給与と公的年金

年金は計算済みの雑所得を手で足す方式から、収入を年間計算へ渡す方式に改める。次は架空の確認済み入力例。

```json
{
  "fiscal_year": 2027,
  "calculation_mode": "filing",
  "salary_income": 9000000,
  "salary_income_adjustment_eligible": false,
  "pension_income": 3000000,
  "pension_is_over_65": true,
  "blue_return_deduction": 0
}
```

`pension_income` は年金収入、`pension_is_over_65` は対象年末時点の年齢区分。年金がある場合は年齢区分を省略できない。年金の課税所得を `misc_income` にも入れると二重計上になるため、`misc_income` には年金以外の雑所得だけを渡す。年金の源泉徴収税額は `other_income_withheld_tax` に含める。

給与収入850万円超では、子ども・特別障害者等の所得金額調整控除の要件を確認する。本人・扶養親族情報から該当すると分かる場合は反映し、他の所得者の扶養親族でもこの控除から一律除外しない。不明なら `salary_income_adjustment_eligible` で確認結果を渡す。申告用は未確認で停止し、試算では適用なしの警告を返す。確認値と親族情報が矛盾する場合も停止する。

年金以外の合計所得は、子ども等の調整後、給与・年金の調整前、繰越損失を引く前の額から求める。給与と年金の重複に対する最大10万円の調整には、280万円上限を適用する前の年金所得を使う。上限によって初めて年金所得が生じた場合に、この10万円調整を追加しない。

結果には `salary_child_adjustment`・`salary_pension_adjustment`・`pension_deduction`・`pension_salary_cap_adjustment`・`pension_income_after_deduction` を返す。上の例では、年金控除85万円、上限による減額25万円、給与・年金の調整10万円、合計所得910万円、納付税額1,342,000円となる。

単体の `tax calc-pension` でも `fiscal_year` を明示する。2027年の正の年金収入には `salary_income_deduction` が必須で、給与がない場合も0を明示する。年間計算ではこの額を給与収入から自動計算する。2025・2026年の旧入力は維持するが、公的年金の旧表の10万円のずれと端数処理は訂正した。

## 繰越損失と検算

`aggregate_income_before_loss_carryforward` は繰越損失を引く前の合計所得金額。基礎控除・配偶者控除・ひとり親控除等の所得制限に使う。`total_income` は繰越控除後の総所得金額等で、医療費・寄附金の計算に使う。単体の `calc-deductions` では前者を `aggregate_income` に渡せる。省略時は従来どおり `total_income` と同額として扱う。

申告用の検算は入力を再計算し、保存結果の主要な金額と比較する。2026年の結果の年分だけを2027年へ書き換えても、税率と内訳の不一致を検出する。

## 残る範囲

- 2027年のふるさと納税上限と高所得特例の判定・加算計算は追加済み。[専用資料](furusato-and-minimum-tax-2027.md)を参照する。住民税資料からの上限は概算であり、自己負担2,000円の保証ではない。
- 高所得特例を年間計算に適用する場合は、対応する所得だけで全所得がそろうことを確認する。金融所得等がある場合の通常税額・申告不要制度を使わない再計算は別途必要で、専用CLIの特例計算が申告書全体を代替するわけではない。
- 株式・FXの分離課税、退職所得の申告、不動産所得、外国税額控除などは既存の対象外範囲を維持する。
- 2027年の公式申告画面・様式との照合は未検証。2027年2月ごろに予定している架空データによる作成コーナー検証と、その後に公開される2027年分の画面確認は別に行う。
