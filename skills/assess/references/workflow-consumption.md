# assess: 消費税の要否と課税状態を確定・保存するとき

この資料は該当する作業でだけ参照します。節番号は元の手順を識別するためのものです。実行コマンドと `docs/`・`skills/`・設定/進捗パスはプロジェクトルート基準、本文中の `references/` はこのSkillの参照フォルダを指します。対象データが既に揃っていれば先行Skillや全手順をやり直しません。

## ステップ3: 消費税の申告要否判定

### 判定フローチャート: 消費税の課税事業者判定

```
Q1. 対象年分と事業・登録・届出の状況を確認する
└── 売上が0であることだけで申告不要とせず、Q2へ

Q2. 基準期間（対象年の2年前）の課税売上高が1,000万円を超えますか？
├── Yes → 【課税事業者】→ 消費税申告必要
└── No → Q3へ

Q3. 特定期間（原則、前年1-6月）について、納税者が選んだ判定基準で
    課税売上高又は給与等支払額が1,000万円を超えますか？
├── Yes → 【課税事業者】→ 消費税申告必要
└── No → Q4へ

Q4. 適格請求書発行事業者（インボイス登録）をしていますか？
├── Yes → 【課税事業者（インボイス登録による）】→ 消費税申告必要
│         → 対象年の2割・3割特例の適用可否を確認
└── No → 課税選択・相続・資産取得等の免税制限を確認し、制限がなければ免税
```

国内個人の特定期間の判定では、課税売上高に代えて給与等支払額を選べる。「どちらか一方が1,000万円を超えたら必ず課税」というOR判定にしない。基準期間・特定期間だけでなく、相続・高額資産等の免税制限も確認する。[国税庁No.6501](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6501.htm)を参照する。

### 消費税の申告方法の判定

課税事業者と判定された場合、以下の申告方法を判定する:

```
Q1. 対象年の2割特例又は3割特例の適用要件を満たすか？
    （登録、基準期間売上、特定期間・相続・資産・短縮課税期間等の除外条件を確認）
├── Yes → 対応する方式で試算し、他方式の対応範囲・適格性を確認して比較
└── No → Q2へ

Q2. 基準期間の課税売上高が5,000万円以下で、簡易課税の届出をしているか？
├── Yes → 簡易課税で申告
└── No → 本則課税で申告
```

確認済み事実を `shinkoku tax check-eligibility --input eligibility.json` に渡し、結果の `status` を確認する。2割特例の計算・保存は2025・2026年、3割特例は2027・2028年に対応する。入力例・未確認項目・未対応例外は `docs/tax-eligibility.md` を参照する。

### 課税事業者区分の確定値を保存

消費税の課税事業者区分を判定したら、判定結果サマリーへ進む前に次の手順で年度DBへ保存する。

1. `shinkoku ledger fiscal-year-show --db-path DB --fiscal-year YEAR` で現在値を確認する
2. 判定結果が課税事業者か免税事業者かをユーザーへ示し、保存してよいか確認する
3. 課税事業者の場合は、次のパッチを `fiscal-year-update` で保存する

以下の該当するパッチを `profile_patch.json` に保存してから、このコマンドを実行する。

```bash
shinkoku ledger fiscal-year-update --db-path DB --fiscal-year YEAR --input profile_patch.json
```

```json
{"taxpayer_status": "taxable"}
```

この段階では申告方法を確定せず、`consumption_tax_method` は更新しない。適用可能な方法の提示までにとどめる。

免税事業者の場合、現在の `consumption_tax_method` と `simplified_business_type` がともに
NULLなら、次のパッチで区分だけを保存する。

```json
{"taxpayer_status": "exempt"}
```

課税事業者から免税事業者へ再判定し、確定済みの申告方法または事業区分が残っている場合は、
ユーザーへ「確定済みの申告方法設定も取り消す」ことを説明して確認する。確認後、次の3キーを
同じパッチで更新し、申告方法と事業区分を明示的に消去する。

```json
{
  "taxpayer_status": "exempt",
  "consumption_tax_method": null,
  "simplified_business_type": null
}
```
